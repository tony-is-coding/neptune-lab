前端使用 Tailwind CSS v4 + 自定义 `np-` 前缀 token。DESIGN.md 中的颜色已映射为：

- `bg-np-background` → Parchment `#f5f4ed`
- `bg-np-surface` → Ivory `#faf9f5`
- `text-np-text-muted` → Olive Gray `#5e5d59`
- `border-np-border` → Border Cream `#f0eee6`
