# Shared 规则

## 范围

- 本包负责共享 TypeScript 类型、协议、设计系统资源、工具链片段和基础设施接口。
- 本包不承载产品特定业务逻辑或具体 engine 实现。

## 改动纪律

- 每个导出变化都视为 API 变化。
- 优先做向后兼容新增，避免破坏性修改。
- 修改导出契约前检查 `../neptune-ai/` 和 `../neptune-engine/` 中的已知消费者。
- shared 模块应保持小、稳定、轻实现。

## 中文要求

- 新增共享契约说明、注释和使用说明优先中文。
- 类型名、字段名、协议名保持原文。

## 验证

- 类型变化运行最窄消费者 typecheck 或测试命令。
- 没有直接验证命令时，说明检查了哪些消费者以及为什么足够。
