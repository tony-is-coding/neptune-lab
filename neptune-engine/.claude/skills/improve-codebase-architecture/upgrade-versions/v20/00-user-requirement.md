# V20 用户需求

## 核心目标

基于 docs/okr-roadmap.md 和项目目标进行对齐，深度研究当前项目还需要优化补齐的点。

## 用户优先级（明确指定）

### P0 — 去 UI 耦合
- SDK 要独立，只有核心逻辑
- UI 是宿主层服务，不应出现在 SDK 层
- 具体检查：React/Ink 依赖是否泄漏到 engine/、state/、types/ 等核心层

### P0 — 无用代码清理
- 优先级高于代码分层
- 死代码/废弃模块会影响架构升级分析
- 具体检查：未引用的导出、废弃的接口实现、已删除功能的残留

### P2 — 代码迁移分层
- 优先级不高
- 保障稳定运行，能够为用户提供可靠的框架能力更重要
- 不做大规模代码迁移，只做必要的边界加固

## 与 OKR 路线图对齐

| V20 方向 | OKR 路线图对应 | 优先级调整 |
|----------|---------------|-----------|
| 去 UI 耦合 | V7 KR2（SDK 入口统一）+ 架构原则 F3 | 保持 P0 |
| 无用代码清理 | V7 新增 KR | 提升至 P0 |
| 代码分层迁移 | V7 KR5（lint:layers）+ KR3（穿透依赖） | 降至 P2 |

## 约束条件

1. 不破坏框架核心能力（agent loop / tool_calling / skill / mcp / hook）
2. 不做大规模代码重写，优先包裹和外扩
3. 改动后 SDK 必须仍可正常工作
4. 遵循"包装不替代"原则
