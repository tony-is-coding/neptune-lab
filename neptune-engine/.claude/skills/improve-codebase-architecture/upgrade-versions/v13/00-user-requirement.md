## 核心需求

深度分析 claude-code/ 目录下的代码，从以下三个维度全面评估优化空间：

1. **性能优化**：运行时性能、内存使用、启动速度、I/O 效率等
2. **效果优化**：SDK 易用性、API 设计合理性、开发者体验等
3. **架构设计**：模块边界、依赖方向、可扩展性、一致性等
