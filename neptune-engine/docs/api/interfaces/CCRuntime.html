    Interface CCRuntime

    CCRuntime 接口

    职责：

    1. 提供 CC 内置工具列表
    2. 初始化 CC 运行时（configs、bootstrap state）
    3. 创建 QueryEngine 实例
    4. 加载 transcript 文件
    5. 管理 SessionContext 相关操作
    6. 注入 MACRO defines
