    • gracefulShutdown(options?: { exit?: boolean; exitCode?: number }): () => void

      优雅关机：注册 SIGINT/SIGTERM 信号处理器

      当收到信号时：

      1. 触发 'engine:shutdown' 事件
      2. 调用 destroy() 清理资源
      3. 退出进程（可选）

      Parameters

      • Optionaloptions: { exit?: boolean; exitCode?: number }

        选项

        • Optionalexit?: boolean

          是否在清理后退出进程（默认 false）

        • OptionalexitCode?: number

          退出码（默认 0）

      Returns () => void

      清理函数，用于手动取消注册
