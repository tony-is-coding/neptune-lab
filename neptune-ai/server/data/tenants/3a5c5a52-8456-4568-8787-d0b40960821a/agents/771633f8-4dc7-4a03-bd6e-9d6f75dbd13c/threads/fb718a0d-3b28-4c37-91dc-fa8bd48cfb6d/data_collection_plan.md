## 数据收集优先级

### 高优先级（立即收集）

1. 金蝶国际最新财务报告
2. 主要竞争对手最新财务数据
3. 行业市场规模与增长数据
4. 股价与估值数据

### 中优先级（后续收集）

1. 历史财务数据（5年）
2. 详细的产品线数据
3. 客户结构数据
4. 技术发展趋势

### 低优先级（补充分析）

1. ESG相关数据
2. 管理层访谈资料
3. 供应链数据
4. 国际市场数据

## 数据质量控制

- 优先使用官方披露数据
- 交叉验证多个数据源
- 注明数据来源与更新时间
- 识别数据局限性与假设
