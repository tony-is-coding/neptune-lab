基于 Figma 设计稿定义的完整产品交互流程。

## 1. 登录流程

### 页面入口
- 路由：`/login`
- 触发条件：未认证状态访问任意受保护路由时自动跳转

### 交互元素

| 元素 | 类型 | 行为 |
|------|------|------|
| Neptune-AI Logo | 品牌标识 | 纯展示，居中于卡片顶部 |
| "Continue with Google" | 按钮 | 预留功能，暂未实现 OAuth |
| Email 输入框 | 文本输入 | type=email，placeholder: `you@company.com` |
| Password 输入框 | 密码输入 | type=password，placeholder: `Enter your password` |
| Remember me | 复选框 | 勾选后 token 持久化到 localStorage（zustand persist） |
| Forgot password? | 文字链接 | 预留功能 |
| Sign In | 主按钮 | 提交登录表单 |
| "Don't have an account? Sign up" | 切换链接 | 切换到注册模式 |

### 登录请求链路

```
前端 Login.tsx handleSubmit()
  → apiClient.login({ email, password })
    → POST /api/v1/auth/login { email, password }
      → 后端 auth.ts: 查 users 表 → bcrypt.compare → 签发 JWT
        ← 返回 { user: { id, name, email, role, tenantId }, accessToken, refreshToken, expiresIn }
  → setAuth(response.user, response.accessToken)
    → zustand store: { user, token, isAuthenticated: true }
      → zustand persist: localStorage['neptune-auth'] = { state: { user, token, isAuthenticated } }
  → navigate('/') → 进入 Home 页
```

### 注册模式
- 点击 "Sign up" 切换到注册表单，新增 Name 输入框
- 注册请求：`POST /api/v1/auth/register { name, email, password, tenantName }`
- 自动创建新租户 + admin 角色

### 异常处理
- 邮箱或密码错误 → 表单上方显示红色错误提示
- 网络异常 → 显示 "操作失败，请重试"
- 401 响应 → 清除 localStorage['neptune-auth']，跳转 `/login`

## 2. Home / Agent 列表

### 页面入口
- 路由：`/`
- 认证要求：需要有效 JWT

### 交互元素

| 元素 | 类型 | 行为 |
|------|------|------|
| 问候语 | 文本展示 | 根据时段显示 Good morning/afternoon/evening + 用户名 |
| 搜索框 | 文本输入 | 过滤 Agent 列表，含麦克风按钮（预留语音输入） |
| ACTIVE AGENTS 标题 | 段落标题 | 大写追踪间距，分隔搜索和卡片区域 |
| Agent 卡片 | 卡片列表 | 3列网格，显示 Agent 图标/名称/描述/状态标签 |
| Agent 卡片点击 | 导航 | 跳转到 `/agent/:agentId`（Agent Chat 页） |

### Agent 卡片结构
- 左上：48px 彩色圆形图标（Agent 名称首字母）
- 标题：Agent 名称
- 描述：Agent 功能简介（灰色小字）
- 右下角：Active（绿色）或 Idle（灰色）状态标签

## 3. Agent Chat（分栏视图）

### 页面入口
- 路由：`/agent/:agentId`
- 布局：左 360px 对话区 + 右侧 Canvas 画布

### 左侧 — 对话区

| 元素 | 类型 | 行为 |
|------|------|------|
| "Today" 时间分割 | 标签 | 居中显示当前日期 |
| 空状态提示 | 引导 | 显示 Agent 头像 + "Start a conversation" |
| 用户消息气泡 | 消息 | 右对齐，深色背景，圆角右上直角 |
| Agent 消息气泡 | 消息 | 左对齐，浅边框，圆角左上直角 |
| 工具调用卡片 | 内嵌卡片 | 显示工具名称 + 状态指示灯（蓝=运行/绿=完成/红=错误） |
| 输入建议按钮 | 快捷操作 | Agent 回复完成后显示，如 "Use Benchmarks" |
| 输入区域 | 文本框 | 底部固定，含附件按钮 + 发送按钮 |
| "Content generated by AI" | 免责声明 | 输入框下方居中灰色小字 |

### 右侧 — Canvas 画布

| 元素 | 类型 | 行为 |
|------|------|------|
| 工具栏 | 顶栏 | 显示 "{Agent名} Output" + Export 按钮 |
| 内容区域 | 画布 | 白色卡片，展示 Agent 生成的产物 |
| 空状态 | 占位 | 图标 + "Generated artifacts will appear here" |

### SSE 流式响应流程

```
前端 handleSend()
  → POST /api/v1/agents/:agentId/chat { content }
    ← SSE event:message { type: "text", content: "..." }  （流式追加）
    ← SSE event:message { type: "tool_use", name: "..." }  （工具调用开始）
    ← SSE event:message { type: "tool_result", output: {...} } （工具调用结束）
    ← SSE event:done { usage: { inputTokens, outputTokens } }  （完成）
```

## 认证状态管理

### 存储位置
- `localStorage['neptune-auth']` — zustand persist 自动同步

### 存储结构
```json
{
  "state": {
    "user": { "id": "...", "name": "...", "email": "...", "role": "admin", "tenantId": "..." },
    "token": "eyJ...",
    "isAuthenticated": true
  },
  "version": 0
}
```

### Token 生命周期
- Access Token 有效期：1 小时
- Refresh Token 有效期：7 天
- 刷新接口：`POST /api/v1/auth/token/refresh`

### 路由守卫
- `ProtectedRoute` 组件包裹所有需要认证的路由
- 未认证 → 自动跳转 `/login`
- 认证过期（401）→ 清除 store + 跳转 `/login`
