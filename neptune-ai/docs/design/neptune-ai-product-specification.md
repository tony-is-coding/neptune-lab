## 1. 产品定位

**一句话描述**：面向企业业务人员的 Agent 配置与运行平台 —— "培养专属 AI 员工"

**核心理念**：非技术用户通过配置 Agent 模板（相当于岗位说明书），接入企业数据，让 Agent 自动上岗工作。用户不需要编写代码，只需要告诉 AI 它的角色是什么、会什么技能、可以读取哪些资料。

```
┌─────────────────────────────────────────────────────────────────┐
│                      Neptune-AI 产品定位                         │
│                                                                 │
│   "每个 Agent 都像一个数字员工，有自己的岗位说明书、技能包       │
│    和知识库。管理员负责招聘和培训，普通员工负责对话和协作。"     │
│                                                                 │
│   ┌─────────────┐    ┌─────────────┐    ┌─────────────┐        │
│   │   配置 Agent  │ →  │   接入数据   │ →  │  Agent 上岗  │        │
│   │  (岗位说明书) │    │  (知识库)    │    │  (对话执行)  │        │
│   └─────────────┘    └─────────────┘    └─────────────┘        │
│                                                                 │
│   用户不需要编程 ──── 只需要配置 ──── Agent 自动执行              │
└─────────────────────────────────────────────────────────────────┘
```

### 5.2 实体详情

| 实体 | 关键属性 | 业务含义 |
|------|---------|---------|
| **Tenant** | name, quota, billing_config | 一个组织/公司，是所有数据的顶层隔离边界 |
| **User** | name, email, role(admin/user) | 系统用户，归属于某个租户 |
| **AgentTemplate** | name, system_prompt, model_config, tools, skills, mcp_servers, constraints | Agent 的"岗位说明书"，定义了角色、能力、限制 |
| **Session** | status, workspace, last_active_at | 一次持续的对话流，workspace 存储对话和记忆 |
| **Document** | name, type, size, path | Agent 的知识库文件，支持 PDF/CSV/MD/JSON |
| **BillingRecord** | input_tokens, output_tokens, cost_cents | 每次对话的用量记录，用于计费 |

### 9.1 Agent 对话完整数据流

```
┌─────────────────────────────────────────────────────────────────────┐
│                  Agent 对话完整数据流                                │
│                                                                     │
│  用户输入 "分析一下上季度营收"                                      │
│       │                                                             │
│       ▼                                                             │
│  ┌─ Desktop ──────────────────────────────────────────────────┐    │
│  │  AgentChat.handleSend()                                    │    │
│  │  ├─ 创建 user message → setMessages                       │    │
│  │  ├─ 创建空 assistant message → setMessages                 │    │
│  │  └─ fetch POST /api/v1/agents/:id/chat                     │    │
│  │     body: { content: "分析一下上季度营收" }                  │    │
│  │     headers: { Authorization: Bearer <token> }             │    │
│  └───────────────────────────┬───────────────────────────────┘    │
│                              │                                     │
│                              ▼                                     │
│  ┌─ Server ───────────────────────────────────────────────────┐    │
│  │  authMiddleware → 验证 JWT → 注入 request.user              │    │
│  │       │                                                    │    │
│  │       ▼                                                    │    │
│  │  QueryDispatcher.dispatch()                                │    │
│  │  ├─ 查询 agent_template (DB)                               │    │
│  │  ├─ getOrCreateSession() (DB + 文件系统)                    │    │
│  │  ├─ new TenantPermissionDelegate() (权限隔离)               │    │
│  │  ├─ AgentEngine.create() (创建引擎实例)                     │    │
│  │  ├─ engine.loadSession() (恢复历史)                         │    │
│  │  └─ engine.query() → AsyncGenerator                        │    │
│  │       │                                                    │    │
│  │       ├── event(text) ────────────→ SSE "message"          │    │
│  │       ├── event(tool_use) ────────→ SSE "message"          │    │
│  │       │    └── Agent 调用 FileRead/Grep 等工具              │    │
│  │       ├── event(tool_result) ─────→ SSE "message"          │    │
│  │       ├── event(text) ────────────→ SSE "message"          │    │
│  │       └── complete ────────────────→ SSE "done"            │    │

│  │  ReadableStream.read() 逐行解析                             │    │
```
