消息块（Block）类型一览

T

Thinking Block 思考块

显示「思考中...」动画 → 完成后「已思考 Xs」，可折叠展开查看完整思考内容

A

Text Block 文本流式输出

逐字流式展示，支持 Markdown 渲染（代码块、列表、粗体等），带闪烁光标

U

Tool Use Block 工具调用

可折叠卡片：工具名 + 状态图标（运行中/完成/错误），展开显示输入参数和输出结果

D

Artifact Block 文档产出

聊天中显示文档卡片（类型标签+标题），点击在右侧面板中打开渲染，支持代码/表格/文档/图片
